# 🌤️ 天气预报网站

一个免费、开源、无需后端的天气预报查询网站，界面风格参考主流游戏官网，支持全球城市天气查询。

## ✨ 功能特性

- 🔍 **城市搜索** — 支持中文、英文城市名（如"北京""Shanghai""London"）
- 🌡️ **实时天气** — 温度、天气状况、体感温度、气压
- 💧 **气象数据** — 湿度、风速、紫外线指数
- 📅 **七日预报** — 未来 7 天最高/最低温及天气图标
- 📱 **响应式设计** — 适配桌面端和移动端
- 🌍 **免费数据源** — 基于 Open-Meteo API，无需注册、无需 API Key
